# 경제·돈·생활이슈 고CTR 포스팅 제목 생성 규칙 V1.0

> 분석 자료: 사용자가 제공한 「별별 이슈들」 게시글 제목 **120개** (2025-11-13~2026-10-10 작성 표기 기준)
>
> 목적: 한국 독자가 네이버 블로그 홈피드·검색에서 관심을 가질 만한 **경제·투자·직장·부동산·자산·소비·결혼 비용** 관련 제목을 생성한다.
>
> 주의: 이는 **제목 문체 및 후킹 구조의 벤치마킹**이다. 함께 전달된 괄호 안 숫자, 게시일만으로 조회수·노출수·CTR·실제 수익을 알 수 없으며, 'CTR이 높다고 검증된 제목'이라고 단정하지 않는다.

---

## 1. 이 블로거 제목의 정체성

**공식:** `나와 가까운 돈 문제 + 구체적 금액·나이·직업 + 비교/갈등/의외의 결과 + 결말에 대한 호기심`

이 스타일은 전통적인 경제기사 제목보다 **돈을 둘러싼 사람들의 현실·사연·사회적 비교**에 가깝다.

- **핵심 소재:** 월급·연봉·순자산·주식·부동산·전세·가족 지원·결혼 비용·축의금·노후·물가·자영업·채용.
- **접근 방식:** 정보 전달만 하지 않고 “나라면?”, “우리 집은?”, “이게 공평한가?”라는 자기 관련성과 판단 욕구를 자극한다.
- **언어:** “요즘”, “현재”, “이 정도”, “진짜 이유”, “근황”, “결과”, “현실”, “이게 맞나요?”처럼 구어체 중심.
- **리듬:** 설명을 길게 하지 않는다. **상황 1개 + 궁금증 1개**가 기본.
- **중요한 차이:** 종종 돈 관련 문제를 **갈등의 서사**로 제시한다. 단순히 “축의금 평균”이 아니라 “축의금 얼마 냈다가 왜 갈등이 생겼나?”로 바꾼다.

## 2. 벤치마크에서 반복된 8가지 장치

| 장치 | 사용 목적 | 추상화한 구조 |
|---|---|---|
| 현재성 | 새로운 소식처럼 보이게 함 | `요즘/현재/올해 + 달라진 X` |
| 구체적인 숫자 | 한눈에 규모가 들어오게 함 | `월 500만원 / 순자산 10억 / 30대 / 10년` |
| 경제적 비교 | 내 위치를 점검하게 함 | `평균 vs 중간값 / 소득 vs 지출 / 국장 vs 미장` |
| 사연·딜레마 | 독자의 의견을 유도 | `A를 요구했더니… 공평한가요?` |
| 결과 공개 유보 | 후속 내용을 궁금하게 함 | `X에 투자한 뒤 벌어진 일 / 현재 상황` |
| 숫자·순위·계급표 | 한눈에 비교하고 저장하도록 함 | `TOP 5 / 6가지 / 소득별 구간표` |
| 의외성·반전 | 통념과 다른 지점을 제시 | `잘 버는데 돈이 안 남는 이유` |
| 독자 직접 질문 | 댓글·참여 유도 | `이 정도면 중산층일까요?` |

**금액은 강한 후킹 요소이지만, 정확성이 숫자의 크기보다 중요하다.** 금액·비율·수익률·순위·연봉표에 근거가 없으면 임의로 만들지 않는다.

## 3. 제목 제작 유형 16가지

아래 예시 제목은 **생성 구조 시연용으로 새로 작성**했다. 상황이나 금액을 제시한 사례형 문장은 실제 사건을 주장하는 것이 아니라 가상의 구성이다. 게시할 때는 사실·자료 확인이 선행되어야 한다.

### 01. 현재 상황·사회 현상형
- **공식:** `요즘/현재 + 경제 주체/지역/업종 + 달라진 상황/현실`
- **예시:** `요즘 동네 카페 사장님들이 매출보다 먼저 확인하는 숫자`
- **용도:** 소상공인, 자영업, 채용, 소비·주거 트렌드.
- **주의:** “심각하다”, “다들 난리”는 실제 근거와 범위를 확인한 경우에만.

### 02. 연봉·자산 수준 비교형
- **공식:** `연령/직업 + 연봉/순자산 + 평균·중간값·분포 + 의외의 차이`
- **예시:** `30대 평균 순자산만 보면 착각하기 쉬운 이유`
- **용도:** 임금 통계, 소득구간, 가계금융복지조사, 평균과 중위값.
- **주의:** 전국 통계를 서울·특정 직종에 적용하지 않는다.

### 03. 숫자·순위·TOP N형 ★필수 포함
- **공식:** `돈 문제/대상 + TOP N/상위 N%/N가지/순위`
- **예시:** `신혼부부가 집 구할 때 따져볼 비용 5가지`
- **용도:** 정보 정리, 구간별 비교, 체크리스트, 실질적인 순위.
- **주의:** `1위`, `상위 1%`, `계급표`는 기준·조사연도·출처가 있을 때만 사용.

### 04. 경제적 계층·자기 위치 확인형
- **공식:** `내가/우리 집이 + 중산층인지/어느 소득구간인지 + 확인 방법`
- **예시:** `우리 집은 중산층일까? 소득보다 먼저 봐야 할 기준`
- **용도:** 순자산, 가구별 소득, 주거비 부담, 금융자산.
- **주의:** 사람·지역을 '수준 낮음' 등으로 낙인찍지 않는다. 분류 기준과 통계의 한계를 설명한다.

### 05. 금액 + 갈등·공평성 질문형
- **공식:** `구체적 돈/재산 + 가족·연인·직장 관계 + 이게 맞나요?`
- **예시:** `신혼집 보증금 한쪽이 더 냈다면 생활비도 반반일까요?`
- **용도:** 결혼자금, 명절 용돈, 가족 지원, 공동명의, 축의금.
- **주의:** 가상의 사연을 실제 제보나 실화처럼 꾸미지 않는다.

### 06. 투자 결과·후일담형
- **공식:** `종목/자산 + 투자 기간/투입금 + 이후 결과/근황`
- **예시:** `매달 ETF를 적립했다면? 5년 수익률보다 중요한 변수`
- **용도:** 주식·ETF·비트코인·부동산·장기투자 회고.
- **주의:** 수익·손실·기간·투자 경험은 반드시 데이터 또는 실제 사례를 확보한 뒤 작성.

### 07. 집중투자·선택의 대가형
- **공식:** `주식/집/퇴직금 중 선택 + 예상 밖의 리스크/기회비용`
- **예시:** `집 살 돈을 주식에 넣으면? 수익률보다 무서운 변수`
- **용도:** 몰빵 투자, 주택자금 운용, 노후자금, 레버리지.
- **주의:** '무조건 오른다', '반드시 사야 한다' 같은 투자 확언 금지.

### 08. 직장인 월급의 역설형
- **공식:** `연봉·월급은 높은데 + 왜 돈이 안 남는지/불안한지`
- **예시:** `월급 500만원인데 저축이 어렵다면? 먼저 볼 지출 3가지`
- **용도:** 가계부, 고정비, 실수령액, 소비 습관, 대출 부담.
- **주의:** 금액은 조건·예시 또는 실제 통계로 명시.

### 09. 직업·회사·채용 반전형
- **공식:** `회사/직업 + 연봉/성과급/복지/채용 + 뜻밖의 현실`
- **예시:** `대기업 성과급이 높아도 실수령액이 다른 이유`
- **용도:** 취업, 연봉협상, 대기업·중소기업, 공기업, 퇴직.
- **주의:** 기업별 연봉·성과급은 공시·공고·보도 등 확인 후.

### 10. 부동산·주거 수준 비교형
- **공식:** `지역/평형/자금 + 요즘 집값/청약/거주 현실 + 반응`
- **예시:** `서울 아파트 9억이면 대출은 얼마나 필요할까?`
- **용도:** 시세, 청약, 전세, 실거래, 주거비, 평면도.
- **주의:** 같은 지역이라도 시점·단지·면적이 다르면 가격이 달라진다.

### 11. 가족·결혼 돈 문제형
- **공식:** `결혼/가족 행사 + 얼마/누가 부담 + 의견이 갈리는 지점`
- **예시:** `결혼자금 부모님이 지원했다면 공동명의는 어떻게 봐야 할까?`
- **용도:** 축의금, 산후조리원, 부모 부양, 상속·증여, 혼수.
- **주의:** 한쪽의 경험담을 전체 세대·성별의 특성처럼 일반화하지 않는다.

### 12. 통계의 반전·상식 점검형
- **공식:** `다들 이렇게 믿는데 + 실제 지표/중간값/분포를 보면?`
- **예시:** `평균 연봉만 믿었다면? 중간값이 알려주는 다른 현실`
- **용도:** 통계청·한국은행 등 공식 데이터 분석.
- **주의:** 설문 인식과 공식 지표를 구별하고 모수·조사 시기를 밝힌다.

### 13. 시간 경과·전후 비교형
- **공식:** `N년 전 선택 vs 지금 + 무엇이 바뀌었나`
- **예시:** `5년 전 전세를 선택했다면? 지금 다시 계산해볼 비용`
- **용도:** 물가, 집값, 금리, 환율, 투자, 임금상승.
- **주의:** 과거 가격과 현재 가격은 동일 기준으로 비교.

### 14. 생활비·소비 실수형
- **공식:** `누구나 하는 지출 + 모르고 새는 돈 + N가지`
- **예시:** `배달비 별것 아닌 줄 알았는데, 한 달 합치면 달라지는 지출`
- **용도:** 소비 패턴, 구독료, 차량비, 자녀 교육비, 명절 지출.
- **주의:** '가난한 사람의 특징' 같은 낙인보다는 재정 행동·구조에 초점.

### 15. 제도·지원금·실용정보형
- **공식:** `연도 + 제도/수당/환급 + 달라지는 점/확인법/신청방법`
- **예시:** `2026 실업급여 수급 조건, 퇴사 전 확인할 항목 4가지`
- **용도:** 세금, 연금, 청약, 실업급여, 지원금, 공제.
- **주의:** 시행 전/발의/확정/지급 중 단계를 구분하며 신청 조건을 검증.

### 16. 사회적 논쟁·찬반 질문형
- **공식:** `돈과 연결된 논쟁의 사실관계 + 여러분이라면?`
- **예시:** `맞벌이 부부 생활비 반반, 소득이 다르면 공평할까요?`
- **용도:** 가사노동·경제권·공정성·증여·가족 부양.
- **주의:** 자극적 갈등을 위해 주장·발언을 허위로 조작하지 않는다.

## 4. 검색형과 홈피드형을 함께 만드는 법

### A. 홈피드형
독자가 스크롤하다 궁금해하도록 **사람·금액·갈등·현재 상황**을 앞에 배치한다.

- `월 500만원을 버는데도 돈이 안 남는 이유`
- `9억 신혼집 공동명의, 의견이 갈리는 이유`
- `요즘 직장인들이 퇴사보다 먼저 계산하는 숫자`

### B. 검색형
검색어가 명확하게 드러나도록 **핵심 키워드**를 제목 초반에 배치한다.

- `2026 직장인 연봉 실수령액, 세전·세후 계산법`
- `신혼집 공동명의 장단점, 지분과 증여세 확인사항`
- `30대 평균 순자산과 중위값, 통계 보는 방법`

### C. 혼합형 — 기본 추천
**핵심 검색어 + 숫자·상황 + 의외의 사실/질문**을 한 문장으로 잇는다.

- `30대 평균 순자산, 숫자만 보고 놀라면 안 되는 이유`
- `2026 연봉 실수령액, 월급보다 먼저 확인할 3가지`
- `신혼집 공동명의 9억, 돈 낸 비율 다르면 어떻게 될까?`

**권장:** 사용자의 목적이 네이버 홈판 유입과 검색 유입을 함께 노리는 경우 **혼합형을 기본**으로 사용한다. 플랫폼의 실제 CTR을 보장하는 공식은 아니다.

## 5. 숫자·순위형 사용 원칙 (핵심)

- 20개 제목을 만들 때 **숫자·순위·금액형 6~8개**를 목표로 한다. 단, 주제 특성상 숫자가 부자연스럽다면 억지로 넣지 않는다.
- 숫자는 다음 다섯 갈래를 구분한다.

| 종류 | 권장 표현 | 필요한 검증 |
|---|---|---|
| 금액 | 월급 300만원, 전세 3억원 | 실사례·가정·시세 여부 |
| 기간 | 5년 적립, 10년 장투 | 기간과 시작·종료시점 |
| 개수 | 지출 실수 3가지, 체크포인트 5개 | 본문에 실제로 3·5개 포함 |
| 통계 | 평균 연봉, 상위 10% | 조사연도, 표본, 통계기관, 산식 |
| 순위 | TOP 5, 1위 | 비교 대상을 모두 포함한 일관된 순위 기준 |

- `직장인 연봉 계급표`, `거주지 계급도` 등은 **공식 기준인지, 온라인에서 유통되는 비공식 분류인지 반드시 표시**한다.
- `순자산 30억`과 `연봉 1억`은 비교 단위가 다르다. 소득·자산·부채·실수령액을 혼용하지 않는다.
- 기업 주가·공무원 봉급·정책 시행일 같은 변동 정보는 발행 직전에 다시 검증한다.

## 6. 감정 버튼과 어휘 사전

| 감정/동기 | 잘 쓰이는 어휘 | 주의 |
|---|---|---|
| 자기 비교 | 평균, 중산층, 상위 몇 %, 이 정도 | 비교 집단 명시 |
| 호기심 | 의외, 뜻밖, 알고 보니, 진짜 이유 | 내용에 실제 반전 필요 |
| 공감 | 월급이 안 남는다, 빠듯하다, 현실 | 경험담 조작 금지 |
| 갈등 | 반반, 공평한가, 눈치, 말해야 할까 | 성별·세대 비하 지양 |
| 현재성 | 요즘, 2026, 최근, 현재 | 최신 자료 확인 |
| 이야기 | 그 후, 결국, 결과, 근황 | 사건의 결과 확인 |
| 실용성 | 확인하는 법, 기준, 총정리, 5가지 | 본문에 확인 절차 제공 |

**권장 문장 종결:** `…이유`, `…결과`, `…근황`, `…현실`, `…맞나요?`, `…얼마나 될까?`, `…확인하는 방법`, `…N가지`, `…이 정도?`

**주의 종결:** `인생역전`, `무조건`, `100%`, `전 국민 난리`, `폭망`, `박살` 등은 실제로 입증되지 않으면 쓰지 않는다.

## 7. 제목 길이·문장 구조 가이드

1. 가능한 한 **제목 하나에 메시지 하나**만 담는다.
2. **첫 10~18자**에 돈·직업·연령·회사·지역 등 주제를 드러낸다.
3. 기본은 **한국어 약 18~38자**를 시작점으로 하되, 의미가 전달된다면 길이에 집착하지 않는다.
4. 금액은 가능하면 `1억원 / 500만원 / 30대 / 10년`처럼 눈에 띄는 단위로 표현한다.
5. 물음표는 실제 독자의 궁금증을 자극할 때만 사용한다. 느낌표·말줄임표 남발은 지양한다.
6. 호기심을 남기더라도 **주제 전체를 숨기는 제목**(`이게 실화?`만 제시하는 등)은 피한다.
7. 사용자가 자료를 제공하지 않았다면 실명·기업명을 넣어 실화처럼 보이게 만들지 않는다.
8. 사연형은 `실제 사연/독자 제보/가상 사례/설문 응답`을 구분한다.

## 8. 제목을 만들기 전 주제별 검증 체크

**직장·연봉:** 세전·세후, 월급·연봉, 평균·중위값, 기준연도, 성과급 포함 여부.

**주식·코인:** 수익률 기간, 배당 포함 여부, 매수·매도 시점, 세금·수수료, 손실 가능성, 출처.

**부동산:** 실거래·호가 구분, 면적, 지역, 거래일, 대출금리, 세금·청약 요건.

**가계·가족:** 실제 사례인지, 한 가구의 상황을 전국 평균처럼 일반화했는지.

**지원금·세제:** 현재 시행 여부, 자격·소득·연령 조건, 신청기간, 관계기관 공지.

**설문·랭킹:** 조사기관, 표본, 기준, 조사 시점, 의견 조사와 객관 통계 구분.

## 9. 생성 후 품질 검수표

각 제목을 아래 항목으로 자체 검토한다. 총점은 **편집 품질 점검용**이며 실제 CTR 예측 확률이 아니다.

| 기준 | 점수 | 확인 질문 |
|---|---:|---|
| 주제의 명확성 | 0~2 | 누구의 어떤 돈 문제인지 보이는가? |
| 구체성 | 0~2 | 금액·연령·기간·기업·지역·행동 중 알맞은 하나가 있는가? |
| 호기심·반전 | 0~2 | 본문에서 답할 만한 질문이 있는가? |
| 검색 적합성 | 0~2 | 검색어로 쓸 법한 표현이 제목에 있는가? |
| 사실성·정직성 | 0~2 | 과장·허구·오해 소지가 없는가? |

- **8~10점:** 우선 검토 후보
- **6~7점:** 문장이나 키워드 수정
- **5점 이하:** 재작성
- **사실성 0점:** 점수 총합과 관계없이 **사용 금지**

동일 주제에서 제목 3개 이상이 `…이유`로 끝나거나 문장 뼈대가 반복되면 다양하게 다시 쓴다.

## 10. 제목 20개 생성 시 권장 구성

**주제에 관련된 유형만 선택한다. 아래 배분은 가이드이며 모든 키워드에 강제하지 않는다.**

| 묶음 | 권장 개수 |
|---|---:|
| 평균·중간값·자산 비교·계층 확인 | 3 |
| 금액/숫자/순위·TOP N | 4 |
| 갈등·공평성·사연·딜레마 | 3 |
| 직장·월급·소비 현실 | 3 |
| 투자·부동산 선택과 결과 | 3 |
| 현재 이슈·통계의 반전 | 2 |
| 실용 검색형(신청·조회·계산·체크리스트) | 2 |
| **합계** | **20** |

> 숫자형은 위 유형과 **중복 가능한 속성**이다. 전체 결과 중 6~8개가 금액·기간·N가지·순위 등 분명한 숫자를 포함하도록 조정한다. 가상의 정확한 통계·수익·사건은 만들어내지 않는다.

## 11. 새로운 주제에 적용한 제목 예시

다음은 **샘플 주제와 표현 예시**이며 실측 수치나 실제 제보를 주장하지 않는다.

### 주제 A: `직장인 월급·자산`
1. `월급은 올랐는데 왜 통장 잔고는 그대로일까?`
2. `2026 직장인 평균 연봉, 중간값까지 봐야 하는 이유`
3. `연봉 1억원이면 중산층일까? 소득과 자산은 다릅니다`
4. `세후 월급 400만원, 고정비 계산하면 달라지는 현실`
5. `내가 중산층인지 확인하는 방법, 이 3가지부터 보세요`

### 주제 B: `결혼·가족 돈 문제`
6. `결혼자금 부모 지원 1억원, 증여세는 어떻게 달라질까?`
7. `생활비 반반이 공평할까요? 맞벌이 부부가 갈리는 지점`
8. `축의금 10만원, 친한 친구에게도 같은 기준일까?`
9. `9억 신혼집 공동명의, 돈 낸 비율 다르면 확인할 것`
10. `부모님 용돈, 형제마다 소득이 다른데 똑같이 내야 할까?`

### 주제 C: `투자·부동산`
11. `주식에 몰빵하기 전, 수익률보다 먼저 계산할 숫자`

13. `집 살 돈을 주식에 넣을까? 두 선택의 기회비용`

15. `요즘 전세보다 월세가 유리하다는 말, 무엇부터 비교할까?`

### 주제 D: `경제 이슈·생활비·통계`
16. `요즘 자영업자들이 월매출보다 순이익을 먼저 보는 이유`

19. `중소기업 월급, 대기업과 비교할 때 놓치는 복지의 가치`
20. `공기업 연봉 순위, 초봉과 평균 보수를 구분해야 하는 이유`

## 12. 재사용 가능한 마스터 프롬프트

아래 내용을 Hermes Agent, Codex 또는 ChatGPT의 제목 생성 작업에 그대로 넣고 **[키워드]**만 바꾼다.

```text
당신은 네이버 블로그의 경제·재테크·사회경제 이슈 전문 고CTR 제목 에디터다.

[입력 키워드]
{키워드}

[목표]
'돈의 크기 + 내 현실과의 관련성 + 의외의 비교/질문/결과'라는
제목 구조를 활용해 네이버 홈피드와 검색 유입을 함께 고려한
독창적인 한국어 경제 포스팅 제목 20개를 생성한다.

[제목 제작 기준]
1. 키워드를 제목 앞부분에 자연스럽게 배치한다.
2. 관련 있는 경우 직업, 연령대, 월급, 연봉, 순자산, 투자금,
   주거비, 기간 등의 구체적인 경제적 맥락을 제시한다.
3. 요즘 상황형, 숫자·순위형, 자산 비교형, 딜레마형,
   투자 결과형, 직장인 현실형, 통계 반전형, 실용 검색형을
   다양하게 활용한다. 하나의 어미나 구조만 반복하지 않는다.
4. 전체 20개 중 6~8개에 숫자, 금액, 기간, TOP N,
   N가지 중 적합한 요소를 포함한다.
5. 구어체와 질문형을 자연스럽게 사용한다.
   (예: '이게 맞나요?', '왜 남는 게 없죠?', '진짜 이유')
6. 경제적 자기 비교와 현실적인 선택의 고민을 강조하되
   특정 성별, 연령, 소득계층, 지역을 비하하지 않는다.
7. 통계와 숫자는 검증된 사실만 제시한다. 모르면
   수치를 지어내지 않고 '확인할 기준', '무엇이 다를까'처럼 쓴다.
8. 실제 투자 수익, 기업 공시, 시세, 정책 변경, 직장인 사연을
   근거 없이 단정하거나 체험담처럼 꾸미지 않는다.
9. 투자 수익 보장, 확정적 시장 예측, 허위 긴급성,
   과장된 '무조건/100%' 표현을 사용하지 않는다.
10. 검색 의도가 강한 제목과 홈피드 후킹형 제목을 균형 있게 만든다.

[출력]
- 번호 / 제목 / 제목 유형 / 주력 검색 키워드
- 20개 작성, 의미가 겹치는 제목은 제거
- 최종 우선 추천 3개와 선정 이유를 간단하게 제시
- 제목의 내용을 뒷받침할 근거가 필요한 경우 '검증 필요' 표시
- 실측 CTR을 알 수 없다면 CTR 성과가 입증되었다고 말하지 않는다.
```

## 13. 운영 메모

- **벤치마킹은 문장 구조를 가져오는 것**이지 기존 제목을 단어 몇 개만 바꿔 복사하는 일이 아니다.
- 댓글이 많아 보이는 소재는 돈 그 자체보다 **관계·비교·억울함·선택의 결과**를 담고 있을 가능성이 있다. 단, 댓글 수는 CTR의 직접 지표가 아니다.
- 첫 발행은 `홈피드형 2개 + 검색형 2개 + 혼합형 2개`를 비교할 후보군을 만든 뒤, 주제 사실관계와 본문 부합 여부로 결정하는 방식을 권장한다.
- 실제 성과를 개선하려면 게시일, 노출, 클릭, CTR, 유입 경로, 스크롤·체류 시간 등의 데이터를 별도로 축적한다.
- 유행·시세·정책을 다룬 제목은 시간이 지나면 사실관계가 바뀌므로 **발행일 기준 자료를 다시 확인**한다.
