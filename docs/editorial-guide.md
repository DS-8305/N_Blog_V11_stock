# 자료 화면 기반 주식 원고

새로 생성하는 자료 화면 작업은 `reader_focused_v2`를 사용합니다. 이전 작업에서 이 필드가 없으면 기존 원고·태그·제목 규칙과 저장된 fingerprint를 유지합니다.

작성일의 실제 거래 현황부터 조사합니다. 주말·휴장일이면 원천 자료 및 거래소 캘린더로 확인한 직전 실제 거래일을 사용합니다. 금요일을 무조건 직전 거래일로 잡거나, 오래된 기업현황 표를 작성일 시세로 바꾸어 표시하지 않습니다. 주가·52주 최고/최저·시총·선택한 1개월 수익률은 같은 거래일과 가격 기준을 맞춥니다. KRX와 KRX+NXT는 서로 바꾸어 취급하지 않습니다.

제목은 검토된 사업 개수나 시총처럼 본문에서 설명하는 숫자로 후킹합니다. 임의의 상승률·목표가·순위는 넣지 않습니다. 도입은 회사 설명, 주요 사업, 영위 분야를 세 줄로 소개합니다. 기존 다섯 소제목과 이미지 순서를 유지하며 다음 내용을 씁니다.

1. 회사가 제공하는 제품·서비스를 소개합니다.
2. 기준일 주가, 52주 최고/최저와 시총을 구체적으로 언급합니다. 1M 수익률은 같은 기준일의 별도 검토 자료가 있을 때 추가합니다.
3. 검토한 연간 차트의 상승·하락·횡보, 최근 구간의 변화와 거래량을 짧게 설명합니다. 고가·저가 두 수치만으로 추세나 거래량을 추정하지 않습니다.
4. 사업부문별 실제 제품·기능·고객 내용을 씁니다. 추상적인 읽기 요령으로 대체하지 않습니다.
5. 확인한 주의점과 긍정 요인을 연결한 뒤, 별도로 검토된 `outlook.value.growthImpact`의 사업 → 매출·이익 기여 가능성 문장으로 마무리합니다. 사업 이름만으로 성장 경로를 만들어내지 않습니다.

출처는 제공자 이름과 기준일을 링크 없이 표시하고, 중복 없는 해시태그를 10개 씁니다. 조사 자료의 `marketResearch`도 공개 출처 이름에 포함합니다. 캡처 2·3·4는 현재 구성과 원본 비율을 유지합니다. 1은 회사 소개 제목과 소개 본문까지, 5는 재무 차트와 실제 표까지 넓은 원본 화면으로 검토할 수 있습니다. 확대·합성·수치 수정으로 원본을 대체하지 않습니다. 사이트의 고정 표 열 때문에 자동 가림 검사에 걸리는 넓은 미리보기는 승인된 캡처로 취급하지 않습니다.

새 작업은 실제 자료 화면 5장과 검토한 금융 사실을 함께 사용합니다. 화면 캡처가 숫자나 기업 설명을 자동으로 인증하지는 않습니다.

제목 후보는 회사 소개·사업 질문·사업 구조·규모·가격 읽기·초보자 상황·체크포인트의 관점을 활용하며, [고CTR 제목 생성 규칙](high-ctr-title-rules.md)의 혼합형 공식(검색 키워드 + 팩트 숫자 + 호기심 유도)을 따릅니다. 회사와 주요 사업을 넣고, 본문이 답하는 사실 연결을 가진 후보 가운데 구체성과 길이로 선택합니다. 클릭률 예측값은 만들지 않습니다.

금액은 원천 값을 보존하면서 `450조 원`, `7만 5,000원`처럼 표현합니다. 소수나 안전하게 정수로 분해할 수 없는 값은 원천 정밀도를 유지합니다. 사업별 매출 비중이 없으면 추정하지 않습니다. 실적 화면의 숫자는 별도 사실 계약 없이 새 주장으로 추가하지 않습니다.

본문·소제목·캡션·출처 줄과 줄바꿈을 포함해 기본 1,200–1,500자(공백 포함, 2026-10-24~ 신규 기준 / 이전 작업 800–1,000자)를 검사합니다. 제목과 태그는 제외합니다. 사실이 길면 임의로 자르거나 반복 문장으로 분량을 채우지 않습니다. 검수 결과를 보고 `post.json`의 설명 문장을 편집하거나 작업 생성 시 분량을 지정하세요.

PNG 5장과 캡션을 시각 검토한 뒤 `assets:approve`를 실행합니다. 이후 `post:review-basis`로 현재 원고와 근거를 열람하고, 사실·제목에 대한 답·의견 구분·권유 표현·캡션을 실제로 읽은 사람이 `post:approve`로 확인합니다. 검토는 운영자의 확인 기록입니다. 정규식만으로 임의의 한국어 기업 사실을 모두 검증한다고 보장하지 않습니다.

제목·본문·캡션·태그·근거·이미지를 수정하면 현재 원고 승인도 무효화됩니다. 입력을 시작한 작업은 수정하지 말고 새 작업을 만드세요. 모드 필드가 없는 기존 작업은 기존 원고·이미지 승인 계약을 유지합니다.
